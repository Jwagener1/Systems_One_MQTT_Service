# Database Metrics — Collection Rules

This file is the single source of truth for **how each metric is collected** per customer schema. Edit the cells in plain English to tell the collector exactly what you want — the implementation in `ItemLogQuery.cs`, `SnowsoftItemLogQuery.cs`, `MadibanaItemLogQuery.cs`, `TwinsaverItemLogQuery.cs`, and `FreightSnapItemLogQuery.cs` should match what is written here.

**Window:** every metric is calculated over the rows whose timestamp falls inside `[Now − 10 min, Now − 5 min)` in local PC time. The filter column is `ItemDateTime` for the Default schema, `Item_Date_Time` for Snowsoft and Madibana, `Print_Date` for Twinsaver, and `ScanDateTime` for FreightSnap.

**Tables:** `Default → ItemLog`, `Snowsoft → tbl_Scanned_Items`, `Madibana → tbl_Measurement`, `Twinsaver → tbl_Line_Data`, `FreightSnap → FreightScans`.

A cell of `—` means the metric is **not collected** for that customer.
